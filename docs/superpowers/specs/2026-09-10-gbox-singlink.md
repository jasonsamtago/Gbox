# Gbox SingLink direct TCP source integration — 2026-09-10

User goal: Gbox must consume the actual SingLink SDK, with identifiable source versions. This slice adds an opt-in core build and native outbound adapter. User delegated development and expressly requests no tests; only source, offline compilation, static analysis and review are authorized here. Runtime connectivity, concurrency, production, CDN, UDP and Node integration are not established by this slice.

## Architecture and alternatives

Chosen: public adapter glue plus an explicit offline developer build entry point. Private SDK source stays in its private repository. The public default Go dependency graph stays unchanged. The glue is stored as `tool/singlink/outbound.go.in`; an explicit Go build overlay substitutes the disabled outbound file only for the opt-in build. A temporary Go workspace includes the existing wrapper and an exact git-archived SDK revision; the wrapper retains its existing local mihomo replacement. No persistent generated source or absolute machine paths are committed.

A build tag alone was rejected because existing setup.dart runs go mod tidy, which inspects inactive tags and would attempt private downloads. Unconditional private dependencies or public vendoring were rejected because they break normal public builds or publish private SDK code. The optional overlay uses Go's documented -overlay Replace map; the new script is only a compiler orchestrator and never launches the resulting core.

## Public parser and adapter

- Append constant.SingLink to AdapterType (no renumbering); String returns SingLink. Parse type `singlink` using SingLinkOption and NewSingLink. Reject enabled outer smux with a fixed error, because this adapter already multiplexes. Preserve normal auto-close registration.
- Common options in outbound/singlink.go: BasicOption inline, Name/Server/Port/Token/SNI (`name`, `server`, `port`, `token`, `sni`), UDP bool, SkipCertVerify bool, Transport string, MaxPending/MaxStreams/ReceiveWindow integer, SetupTimeout/OpenTimeout/WriteTimeout integer milliseconds. Supported transport empty or `direct-tls`; reject UDP, insecure verification, unsupported transport. Do not print token/config in errors or JSON. Clear unsupported-build error in singlink_disabled.go with !singlink tag.
- Defaults: MaxPending64, MaxStreams128, ReceiveWindow262144, each timeout10000ms. Zero means default. Bound pending/streams1..1024; window1..1048576 and streams*window<=67108864; timeouts1..600000ms. Token exactly64 hex characters decoding to32 bytes and not all zero; generic errors. Require nonempty Name, valid target.Encode-compatible Server+Port1..65535; SNI defaults Server, custom SNI must be valid DNS/IP and no zone, standard TLS verifies certificates. Reject malformed options before constructing any networking helper.
- Enabled constructor creates Base using all applicable BasicOption flags, configured BasicOption.NewDialer(Base.DialOptions()), and one tcpclient.Client per adapter instance. No eager network/helper creation. Factory receives the reusable generation lifetime context, uses configured dialer to connect only to fixed server endpoint, then session.Client with strict stdlib TLS config and fixed token. Preserve that context on success; never defer-cancel it at factory return. Own any nonnil raw returned with an error; session owns accepted raw on all returns. Fixed adapter scope; no automatic protocol/carrier retry or fallback.
- DialContext requires nonnil TCP metadata, uses actual destination Host/DstIP and DstPort, not SniffHost; reject bad/UDP target before tcpclient call. Native tcpclient handles request cancellation and stream ownership. Host Pure mapping semantics remain those of normal Gbox call sites.
- Return C.Conn preserving mux native deadlines, CloseWrite and chain/provider/remote metadata without NewConn's extra deadline wrapper. Reuse private outbound conn with N.NewExtendedConn where appropriate, retain AddRef so finalizers cannot close a live adapter; an explicit CloseWrite must preserve reference lifetime as well. No additional IO/deadline watcher or buffer added by this adapter. Wrapper compatibility itself remains runtime-unverified.
- SupportUDP/UOT false; ListenPacketContext unsupported via Base. ProxyInfo preserves dialer proxy and Base metadata. Close invokes tcpclient.Close then waits Done, documenting that a noncooperative host dial/close can block complete drain. Do not call Close from SDK-owned callbacks.
